# StudentProfileApp

A simple Android application developed in **Android Studio** using **Kotlin**, **Java**, and **XML** for the CC106 – Application Development and Emerging Technologies laboratory exam.

## Features

* Student information input form
* Generate a formatted student profile
* Input validation for required fields
* Clear form functionality
* Java–Kotlin interoperability (`ProfileGenerator.java` called from `MainActivity.kt`)
* Clean, responsive Material-inspired user interface

## Technologies Used

* Kotlin
* Java
* XML Layouts
* Android Studio
* Material Design principles

## Project Structure

* `activity_main.xml` – User interface
* `MainActivity.kt` – Handles user interactions, validation, and UI logic
* `ProfileGenerator.java` – Generates the formatted student profile

## Learning Objectives

This project demonstrates:

* Android UI development using XML
* Event handling in Kotlin
* Java–Kotlin interoperability
* Input validation
* Android application design and development best practices

## Sample Output

The application accepts the student's:

* Name
* Student ID
* Course
* Year Level
* Hometown

It then generates a formatted student profile after validating that all required fields have been completed.
